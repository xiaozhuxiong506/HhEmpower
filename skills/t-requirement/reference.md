# 前端需求分析报告规范

## 责任分类

| 分类 | 判定标准 |
|------|----------|
| 前端负责 | 页面结构、交互、展示、前端状态、前端校验或请求组装可由前端独立完成。 |
| 后端负责 | 业务计算、持久化、服务端校验、权限裁决、状态流转或数据生产由后端承担。 |
| 前后端联调 | 前端行为依赖接口字段、枚举、状态、错误码或时序契约。 |
| 待确认 | 不同答案会改变前端范围或方案，且现有事实源不足。 |
| 非前端范围 | 与本次前端目标无直接关系，或明确属于其他角色/系统。 |

## 事实状态

每条结论只允许使用以下状态之一，避免把推断写成事实：

- 产品文档已确认
- 前端源码已确认
- 接口文档已确认
- 多来源一致
- 合理推断，待确认
- 来源冲突
- 资料缺失

## 固定输出模板

资料不完整时仍保留全部章节；用“无”“待定位”“待后端/Torna 确认”或“资料缺失”明确占位，不删章节。只依据产品文档生成时，在主标题后标注“文档初判版”。
