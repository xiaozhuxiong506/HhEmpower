# t-page-max

`/t-page-max + 任务` 是页面工作的全量入口。全部 22 个角色按阶段实际参与，无关角色也须自行核查后返回不适用。

1. 将当前任务的调度模式设为全量，读取 [t-page](../t-page/SKILL.md)，复用其需求分析、画像、规范和页面任务概览，只执行一次。
2. 读取 [共用调度约定](../t-page/orchestration.md) 和 [全量阶段表](orchestration.md)。主 Agent 派发全部角色、收齐真实回执，完成规范/文案审查、代码终审与最终验证。
3. 同一任务后续调用 `t-start`、`t-new-module`、`t-review` 或专业 Skill 时保留全量模式；子代理接单不重新启动入口。用户明确切换模式时采用新选择，新任务不继承历史 max。

全量只改变参与范围，不扩大需求、读写权限或外部访问。只读请求仍只读；缺少子代理工具或角色文件时报告阻塞，不以主 Agent 自检冒充全员完成。Git 提交、推送和发布仍需用户授权。
