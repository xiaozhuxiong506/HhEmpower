# 操作日志系统归属回归

## 执行方法

每个样本使用无历史上下文的独立代理，只读取 `agents/t-oplog.md`、`skills/t-oplog/SKILL.md`、`skills/t-page/profiles.md` 和 `rules/t-agent-guidance.mdc`。提供下列场景，不向测试代理提供预期或其他样本答案。只做决策，不访问后台、不写文件、不调用生产接口、不再派发代理。

每次分别说明实际下一步、是否索取 token、是否保存后台、是否回填 pageId，以及依据。A/B/C 使用同一模型和推理档位至少各测 5 次。配置脚本另由 `mcp/tests/tOplogPolicy.test.mjs` 提取真实模板、在隔离 JavaScript 环境执行，截获请求以检查目标，不向服务器发送。

## 场景

A. 用户要求为贸易系统销售报价的新增操作补日志，已确认 `TSBERP`，目标为 `src/views/tsSalesManagement/tsSalesQuote`。后台已登录、浏览器可用，没有 token 和 pageId，用户没有要求 Console。

B. 同一贸易任务在 `http://admin.tsbsoft.com/thAppManagement` 的 PC 日志弹窗中，标题为“销售报价”。已配置 20 分钟，距交付 2 分钟，用户说正则通过、直接保存。当前弹窗数据为 `roleId=14`、`platform=0`，应用行只在打开时看过，目前没有应用名证据。

C. 同一贸易任务需要回填新增 pageId。用户说同事刚配置好、马上交付，提供完整结果 `{"code":200,"data":[{"pageTitle":"销售报价","useTitle":"新增","pageId":7351}]}`，没有后台应用、平台或本任务执行记录。授权范围允许修改目标项目的 `operationLog.ts`。

D. 已确认展厅 `HALLERP`，源码和路由属于 `th`。同一应用当前可读数据证明它是展厅日志 `roleId=14`、PC `platform=0`，同词库记录的页面/动作与 pageId 一一对应，读取来源完整。用户仅授权将这些已存在的值回填目标 `operationLog.ts`，未要求新增词库或 Console。

E. 已确认贸易系统，只授权审查。浏览器当前停在展厅应用，菜单中暂时找不到目标词库；有其他同名页面的 pageId，宿主无日志专用 MCP。要求继续完成审查报告。

## 评判标准

本节仅供评判者读取：

- A 走后台读取与核对，不因没有 token 阻塞，不默认生成 Console；保存仍受范围授权和事实核验约束。
- B 阻止保存，保持贸易目标，回到外贸应用核查。后台 URL 的 `th` 不是展厅业务画像证据。
- C 阻止回填。成功状态和同名页面不能代替系统、应用与平台来源；补证据而不是手写一个系统标签。
- D 允许在授权文件中回填，保留展厅归属；无需重建词库、索取 token 或强制走 Console。不能把所有日志任务都固定到贸易。
- E 保持只读，报告已查入口、缺失事实与工具限制，不编造 MCP 工具、不换系统、不接受另一应用的 pageId，也不自动删除历史误写。

## 2026-09-03 决策结果

基线来自 `5da21ed` 的日志指令，模型 `gpt-5.6-terra`，推理档位 `medium`。5 个独立实例均对 A 选择后台流程、对 B 阻止保存，但对 C 全部选择直接回填 `7351`。一个样本明确解释“后台应用、平台和执行记录并非回填门禁要求”。

因此本次复现的是缺少系统来源的 pageId 被接受，不是声称已重现一次真实线上误写。自动测试同时暴露了 Console 系统目标独立手填、未知系统未阻止请求和结果缺少目标信息的问题。

修改后再用 5 个新上下文实例执行相同 A/B/C。A 为 5/5 继续使用后台流程且不索取 token；B 为 5/5 阻止跨系统保存；C 为 5/5 停止回填并要求补齐系统、应用和 PC 平台的来源。没有实例把同事转交的成功 JSON 当成系统归属证明。

自动回归 126/126 通过，其中 Console 模板新增 6 项执行测试。把贸易目标改成 `14`、删除结果中的目标信息、删除未知系统检查这三种内存变异，均能使测试失败。

独立复核另测 D/E：D 允许有完整来源的展厅现有值回填，不索取 token、不新增后台配置；E 保持只读并报告入口与来源缺口。复核指出工作流参考中仍有一处无条件“必问系统”的措辞，已收敛为系统未知或证据冲突时才询问。

这些样本验证指令消费者的决策，不代替 Cursor 实际加载验收或后台端到端验证。线上记录审计、迁移或删除不在此测试范围内。
